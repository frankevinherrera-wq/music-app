# Proyecto con React + TypeScript + Tailwind

Bienvenido/a este proyecto es una aplicación desarrollada utilizando tecnologías del ecosistema frontend.

## 🛠️ Tecnologías Utilizadas

*   **React** (Biblioteca para construir la interfaz de usuario)
*   **TypeScript** (Para un código más seguro y tipado estático)
*   **Vite** (Herramienta de empaquetado ultra rápida para el desarrollo)
*   **Tailwind CSS** (Framework de CSS para un diseño rápido y responsivo)
